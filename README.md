# BookMatch

`BookMatch` 프로젝트 루트(모노레포)입니다.  
실제 웹 앱 소스는 `bookmatch-app/` 디렉토리에 있습니다.

## 구성

- `bookmatch-app/`: Next.js 기반 프론트엔드 앱
- `doc/`: 기획/문서 (예: PRD)

## 시작하기 (bookmatch-app)

```bash
cd bookmatch-app
npm install
npm run dev
```

이후 브라우저에서 Next.js 개발 서버 주소로 접속하면 됩니다.
